# Участие в проекте

Для ошибки укажите версию OpenWrt, версию Tailscale Community, язык LuCI и шаги воспроизведения. Для ошибки оформления приложите снимок экрана и ширину окна. Скройте адреса устройств, ключи и другие личные данные.

Перевод находится в `package/luci-app-tailscale-community-ru/po/ru/tailscale.po`. Сохраняйте смысл настройки, параметры `%s` и `%d`, ссылки и имена продуктов. Пишите действие или результат простыми словами. Для нового текста в JavaScript используйте `_('Source text')` и добавьте перевод в каталог.

Перед pull request запустите `python3 scripts/check.py` и сборку через SDK. Изменения оформления проверяйте на русской странице Tailscale при ширине 390, 640 и 1440 пикселей. Для другого языка должно сохраняться оформление исходного приложения.

Тестовая копия исходной страницы хранится в `tests/fixtures`. При обновлении Tailscale Community обновите её вместе со сведениями об источнике и проверьте покрытие перевода.
