# Документация проекта

- Использовать `ru-text` для русского текста, `beautify-github-readme` — для оформления README.
- Сохранять центрированную шапку, одобренную пользователем. Изменять её только по прямой просьбе.
- Использовать Markdown и поддерживаемый GitHub HTML для шапки и раскрывающихся разделов. Не создавать SVG, баннеры и декоративные диаграммы без прямой просьбы пользователя.
- Писать для человека, который устанавливает дополнение на роутер. В README оставлять назначение, возможности, совместимость, установку, помощь, авторство и запрошенное дерево проекта.
- Не добавлять отчёты проверок, внутренние рассуждения и подробности сборки в пользовательские описания.
- Сверять команды и возможности с исходниками. Не обещать совместимость или результаты, которые не проверены.
- Перед публикацией запускать `npm ci` и `npm run lint:md`. Проверять ссылки и отображение на GitHub, включая узкий экран. Линтер проверяет структуру Markdown, качество текста и внешний вид оцениваются отдельно.
